# Fridge Roast: One Line, Biggest Laugh

> My smart fridge's touchscreen lags longer than the milk lasts — it freezes, just never the food.

A deterministic, zero-dependency Node emitter for the [Fridge Roast](https://make.fun/bounty/u-gentle-badger-68-fridge-roast-one-line-biggest-laugh-a7c354bb) make.fun bounty: one line, at most 200 characters, roasting a smart fridge. The line was picked from 8 candidates by pairwise duelling against the judge's rubric (see [CANDIDATES.md](CANDIDATES.md)). It targets the fridge's touchscreen — the part that is supposed to be "smart" — and lands on a double meaning of *freezes*: the screen locks up while the food inside does not stay cold.

## Run

```sh
node main.ts
```

Writes the roast to `/output/entry.txt` (no trailing newline) and verifies the file byte-exact before exiting.
